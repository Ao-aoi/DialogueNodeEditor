# Dialogue Node Editor

Unity向けのノードベースの会話（ダイアログ）エディタツールです。
GraphViewを使用した直感的な操作で、キャラクターの会話や選択肢による分岐、表情変化などを視覚的に作成・管理することができます。

## 特徴

- **ノードベースの直感的なUI**: ドラッグ＆ドロップでノードを繋ぎ、会話のフローを簡単に構築できます。
- **選択肢と分岐**: 1つの会話ノードに複数の選択肢（Choice）を設定し、複雑な分岐を作成できます。
- **キャラクターと表情の管理**: `Character Setting` ノードでキャラクターの立ち絵（Sprite）や表情を管理し、会話ノードとリンクさせることができます。
- **ショートカット対応**: `Ctrl + S` (Macは `Cmd + S`) でのクイックセーブや、`Space` キーでのノード検索メニュー表示に対応しています。
- **デモシーン同梱**: 実際のUIへの組み込み方や実行方法がわかるサンプルが含まれています。

## 動作環境

- Unity 2021.3 以降 (UIElements / GraphView に依存)

## 導入方法

プロジェクトの `Packages` または `Assets` フォルダ内に、本リポジトリ（ディレクトリ）を配置してください。

## 基本的な使い方（エディタ）

### 1. エディタを開く
Unity上部のメニューバーから **`Window > Dialogue Node Editor`** を選択してエディタウィンドウを開きます。

### 2. ノードの作成
グラフ上の何もないところを **右クリック** するか、**`Space` キー** を押すことでノード作成メニュー（Search Window）が開きます。
以下の主要なノードを作成できます：
- **Dialogue Node**: 会話のテキスト、発言者、表情、選択肢を設定するメインのノードです。
- **Character Setting**: キャラクターの名前と、各表情（Normal, Smileなど）に対応する画像（Sprite）を定義するノードです。
- **End Node**: 会話の終了を示すノードです。

### 3. 会話の作成と設定
1. `Dialogue Node` を追加し、「Dialogue Text」に会話文を入力します。
2. 次のノードへ処理を移行するには、右側の `Next` ポートから次のノードの `Input` ポートへ線を繋ぎます。
3. **選択肢を作る場合**: ノード右上の `Add Choice` ボタンをクリックして選択肢ポートを追加し、それぞれのポートから分岐先のノードへ線を繋ぎます。

### 4. キャラクターと表情の設定
1. `Character Setting` ノードを作成し、キャラクター名と各種表情（Sprite）を追加します。
2. `Character Setting` の Output ポートから、対象の `Dialogue Node` の `Character` (Input) ポートへ線を繋ぎます。
3. これにより、`Dialogue Node` 側でそのキャラクターの「表情（Expression）」をドロップダウンから選択できるようになります。
*(※線を繋がずに、Dialogue Node側のドロップダウンで手動でキャラクターを選択することも可能です)*

### 5. データの保存
- ツールバーの **`Save As...`** または **`Save`** ボタンをクリックして、作成した会話データを保存します。
- データは `DialogueContainer` (ScriptableObject) として保存されます。
- `Ctrl + S` (または `Cmd + S`) でも保存可能です。保存されたアセットをダブルクリックすると、エディタで再編集できます。

## 基本的な使い方（ゲームでの実行）

作成した会話データ（`DialogueContainer`）を実際のゲームで再生するには、同梱されているサンプルスクリプトを活用します。

### サンプルスクリプトの構成
- **`DialogueRunner.cs`**: 会話データのフローを管理し、UIに情報を送るメインコンポーネント。
- **`DialogueUI.cs`**: 渡されたテキストのタイピング演出や、立ち絵（Portrait）のスライド表示、選択肢ボタンの生成を行うUI制御スクリプト。

### 再生手順
1. シーン内に `DialogueRunner` コンポーネントをアタッチした空のGameObjectを作成します。
2. `DialogueRunner` の `dialogueData` に、作成・保存した会話データアセット（`.asset`）をアサインします。
3. `DialogueUI` コンポーネントがアタッチされたUIオブジェクトを `dialogueUI` にアサインします。
4. ゲームを再生すると、マウスクリック（左クリック）で会話が進行し、選択肢が表示された場合はボタンをクリックすることで分岐します。

## サンプル（Demo）について
`Samples/Demo/Scenes` フォルダに `Demo Scene.unity` が用意されています。
